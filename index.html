Face à 15 000 événements quotidiens provenant des capteurs autoroutiers, le défi était d'éliminer les fausses alertes sans jamais manquer un incident réel ni bloquer les opérateurs.

  • Résilience à toute épreuve : Circuit Breaker Resilience4j : en cas de timeout du modèle (> 100ms), fallback automatique en VALID_ALARM pour préserver la sécurité.

Mini SGBD Relationnel : Storage, B+ Tree & Query Optimizer

Implémenté en Java pur pour percer le fonctionnement interne des moteurs comme Postgres et MySQL.

  • Couche de stockage : Pages de 4KB avec structure en slotted-pages pour stocker des enregistrements à longueur variable.
  • Buffer Pool Manager : Mise en cache de pages en mémoire vive avec algorithme de remplacement LRU (Least Recently Used) et synchronisation dirty-page sur disque.
  • Index B+ Tree : Index multi-voies équilibré supportant les recherches par clé (point lookups) et les parcours ordonnés par intervalle (range scans).
  • Optimiseur basé sur les coûts : Évaluation statistique de cardinalité, predicate pushdown et sélection dynamique de jointure (Hash Join vs Block Nested Loop).
BPlusTreeIndex.java (Core logic)
public class BPlusTreeIndex<K extends Comparable<K>, V> {
    private final int maxOrder;
    private Node<K, V> root;

    public List<V> rangeScan(K startKey, K endKey) {
        LeafNode<K, V> leaf = findLeaf(startKey);
        List<V> results = new ArrayList<>();
        while (leaf != null) {
            for (int i = 0; i < leaf.keys.size(); i++) {
                if (leaf.keys.get(i).compareTo(endKey) > 0) return results;
                if (leaf.keys.get(i).compareTo(startKey) >= 0) {
                    results.add(leaf.values.get(i));
                }
            }
            leaf = leaf.nextLeaf; // Sequential leaf pointer
        }
        return results;
    }
}

Ordre Causal Distribué sans Coordinateur Central

Comment garantir que chaque nœud observe les causes avant les effets sur un réseau asynchrone non fiable ?

  • Vector Clocks (Horloges Vectorielles) : Chaque nœud maintient un vecteur V[i] incrémenté lors de l'émission et transmis avec chaque trame réseau.
  • Tampon Causal (Causal Buffering) : Un message reçu n'est délivré à la couche applicative que si V_msg[k] == V_local[k] + 1 pour l'expéditeur et V_msg[j] ≤ V_local[j] pour tous les autres nœuds.
  • Résistance aux pannes : Harnais de test déterministe simulant du réordonnancement aléatoire de paquets et une latence réseau de 200ms+.
VectorClock.java (Causal delivery check)
public boolean canDeliver(VectorClock msgClock, String senderId) {
    int senderIdx = nodeIndexMap.get(senderId);
    // Must be the immediate next message from sender
    if (msgClock.get(senderIdx) != this.clock[senderIdx] + 1) {
        return false;
    }
    // Must not depend on any messages we haven't seen
    for (int i = 0; i < numNodes; i++) {
        if (i != senderIdx && msgClock.get(i) > this.clock[i]) {
            return false; // Buffer and wait
        }
    }
    return true;
}
